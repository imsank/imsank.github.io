What this teaching model assumes

It uses a smooth synthetic capacity curve: more concurrency first improves batching, prompt length adds prefill work, and queueing accelerates near estimated capacity. It does not model a particular GPU, engine, scheduler, network, or token-length distribution. Use it to form hypotheses—not to size production.
