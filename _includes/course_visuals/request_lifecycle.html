Static lifecycle summary
  1. Receive and validate the application request.
  2. Render messages into the model's chat template.
  3. Tokenize the rendered sequence.
  4. Admit and queue the request for scheduler work.
  5. Prefill the prompt and create its initial KV state.
  6. Sample the first generated token from prefill logits.
  7. Feed the selected token to decode the following token.
  8. Detokenize stable text and stream it to the client.
  9. Detect EOS or another terminal condition.
  10. Finalize the stream and release request resources.
