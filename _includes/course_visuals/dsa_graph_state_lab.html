Base reachability

The future from a station depends only on its ID. A node-only visited set safely merges repeated arrivals. Stack and queue orders both find the same reachable component.

Override mutation

Reaching X with the override intact permits a different future from reaching X after spending it. The safe key becomes (node, override_available).

Visited timing

Marking at discovery schedules each state once. Marking at removal can place converging states in the frontier multiple times.
